# 5 维审核清单

每个 sub-skill 生成 HTML 后，必须自动跑一遍此清单，并把结果以 markdown 表格返回给小编。
凡是"❌"或"⚠️"项必须人工二次确认。**skill 不得替小编做"通过"判断**。

| # | 维度 | 自动可查项 | 必须人工确认项 |
|---|---|---|---|
| 1 | **错字审核** | 调用语言模型扫一遍，列出疑似错别字（特别注意"建造师/建造士"、"住建部/住建厅"、"专业技术人员/专业技术工人"这类高频混淆） | 专有名词、人名、机构全称 |
| 2 | **排版审核** | 标题层级是否乱、段落是否过长（>5 行）、是否有连续超过 3 个换行、`<section>` 嵌套深度是否合理、所有内联样式是否包含 `font-size` 和 `color` | 整体观感、留白节奏 |
| 3 | **字句审核** | 是否有夸大违规词："最高 / 第一 / 唯一 / 独家 / 国家级"（广告法）、"包过 / 保过"、"百分百拿证" | 营销 tone 是否过激、是否得罪同行 |
| 4 | **政策匹配度审核** | 抓取的政策原文 URL 是否在 `_shared/sources.yaml` 列出的官方源；推文引用的关键日期 / 数字是否原文中存在 | 是否选到正确的关联课程；目标客户画像是否选对 |
| 5 | **政策理解度审核** | 推文中的"解读"段落是否扭曲原意（用语言模型对照原文重新生成一份"客观解读"做差异比对） | 学员视角的"对你意味着什么"是否准确，没有过度承诺 |
| 6 | **配图审核** | 是否调用了 `scripts/gen-image.mjs`（**仅 inline 角色**，hero/footer 不替换）；inline 张数是否达到本类 article-type 的推荐数（见 `_shared/image-generation.md` §3）；图片 URL 是否全部以 `https://pub-e96b09db0cf94150b117f241f58a10f3.r2.dev/{slug}/images/` 开头；① 头图、⑨ 尾图是否仍为 `brand.yaml.article_assets` 固定 URL；是否有 sub-agent 报告的失败项 | **目视检查每张图**：（a）有无文字/字母/数字进画；（b）人物是否东亚/汉族外貌；（c）建筑是否中式；（d）有无国旗/党徽；（e）是否符合"政府政策手册"克制感（不卡通、不霓虹、不夸张） |

## 输出格式

```
## 自动审核结果

| 维度 | 状态 | 说明 |
|---|---|---|
| 错字 | ✅/⚠️/❌ | ... |
| 排版 | ✅/⚠️/❌ | ... |
| 字句 | ✅/⚠️/❌ | ... |
| 政策匹配度 | ✅/⚠️/❌ | ... |
| 政策理解度 | ✅/⚠️/❌ | ... |

## 必须人工二次确认

- [ ] ...
- [ ] ...
```

## 红线（出现任意一条就阻塞发布）

- 政策原文 URL 不在 `_shared/sources.yaml` 列出的官方域名
- 推文引用了原文中不存在的具体数字（金额、人数、日期）
- 出现"最高 / 第一 / 唯一 / 独家"等广告法违禁词
- 出现"包过 / 保过 / 百分百拿证"等承诺式表述
- 头部或尾部固定图缺失（brand.yaml 是 TODO 且未补）
- **配图出现中国国旗 / 党徽 / 特定政府徽标**（学校不是国家媒体）
- **配图人物为非东亚 / 非汉族外貌，或建筑为西方风格**（详见 `_shared/image-generation.md` §5）
- **配图内出现任何文字 / 字母 / 数字**（标题应由 135 编辑器叠加，不进图）
- **① 头图或 ⑨ 尾图被替换为非 `brand.yaml.article_assets` 固定 URL**（配图生成只产 inline 图）
