# 文章目的 × 文体对照

每篇推文动笔前必须先确定 **Q0：本篇核心目的**。
目的不同，标题、开头、节奏、CTA、必带块都不一样。
**目的决定"为什么说"，客户画像（B/C 端，Q1）决定"对谁说"。两个轴独立、互不替代。**

---

## 三种目的（5 个 sub-skill 通用）

| 代号 | 目的 | 典型场景 | 衡量指标 |
|---|---|---|---|
| **fan**（增粉） | 涨粉 / 曝光 / 分享 | 政策大事件借势、热点话题、行业八卦合规向 | 阅读量 / 在看 / 转发 / 新关注 |
| **conv**（转化） | 咨询 / 报名 / 留资 | 招生季、报名截止前、新课上架、补贴窗口 | 扫码量 / 电话量 / 报名表单提交 |
| **hybrid**（混合） | 增粉为主，软带转化 | 90% 的日常推文都走这里，最稳 | 综合 |

> 如果用户/小编犹豫，**默认推荐 hybrid**。fan 和 conv 是极端态。

---

## 选项裁剪：5 个 sub-skill 的 Q0 选项

**5 个 sub-skill 都问 Q0，但选项贴合各自类型**：

| sub-skill | Q0 选项 | 默认推荐 |
|---|---|---|
| **gzcots-policy** | fan / conv / hybrid | hybrid |
| **gzcots-tips** | fan / conv / hybrid | hybrid（提示类天然偏共鸣） |
| **gzcots-guide** | fan / conv / hybrid | conv（指引类天然偏带客） |
| **gzcots-news** | external_pr（对外宣传，≈ fan）/ industry_rel（行业关系）/ internal_celebrate（内部喜讯） | external_pr |
| **gzcots-holiday** | pure_notice（纯通知）/ fan_flavored（节日借势增粉）/ conv_flavored（含营销小尾巴） | pure_notice |

> news / holiday 的目的轴和 fan/conv 的二元不完全重合，因此选项做了本地化裁剪。但都是"在动笔前先决定为什么写"的同一思想。

## fan（增粉）文体规范

| 维度 | 写法 |
|---|---|
| **标题** | 疑问句 / 数字反差 / 反常识 / 资格惊呼。例："广州这条新规一出，70% 的安全员要重新培训" |
| **开头** | 故事 / 痛点 / 反差 / 提问。3 行内必须钩住，不准从政策背景慢慢说起 |
| **主体节奏** | 信息密度适中，多用 ⑤ 重点卡片块 + ⑥ 列表块，便于略读。段落 ≤ 4 行 |
| **数据/政策** | 引用要"惊悚但准确"，数字必须来自 sources.yaml 官网原文 |
| **结尾 CTA** | **软 CTA**："关注我们追踪下一波"/"评论区聊聊你的情况"/"转发给可能用得上的同事" |
| **二维码 / 电话** | 不放，或放在文末小尺寸，不抢戏 |
| **必带块** | ① 头图 → ② 主标题 → ③ 开场钩子段 → 主体（④⑤⑥任意组合） → 结尾软 CTA → ⑨ 尾图 |
| **禁忌** | "立即报名""扫码咨询""限时优惠"——这些会让增粉文显得很销售，掉粉 |

---

## conv（转化）文体规范

| 维度 | 写法 |
|---|---|
| **标题** | **利益 + 资格 + 紧迫**。例："广州户籍 35 岁以下可申请：最高 3000 元技能补贴 6 月 30 日截止" |
| **开头** | 直击痛点（"你的安全 C 证还有 X 天到期"）+ 资格鉴别（"满足以下条件可办"），让目标读者快速对号入座 |
| **主体节奏** | 价值证明（学员案例 / 合作单位 / 历年通过情况，**禁用百分百/包过**）→ 流程 3 步（学/考/证）→ 课程卡 |
| **数据/政策** | 与 fan 一样必须来自 sources.yaml；额外要求：金额、期限、报名入口必须三件齐全 |
| **结尾 CTA** | **硬 CTA**：二维码（醒目）+ 电话（`brand.yaml.school.hotline`）+ 报名入口；按画像走 `audience_design.{b_end\|c_end}.cta_tone` |
| **二维码 / 电话** | 必须有，放在结尾独立 ⑦ CTA 块 |
| **必带块** | ① → ② → 痛点段 → 资格段 → ⑤ 重点卡片（利益清单） → ⑥ 流程列表 → ⑦ CTA（含二维码） → ⑧ B 端引流（C 端文必带）→ ⑨ 尾图 |
| **禁忌** | "最高 / 第一 / 唯一 / 独家 / 国家级 / 包过 / 保过 / 百分百拿证"（广告法 + 红线） |

---

## hybrid（混合）文体规范

- **前 70% 走 fan**：增粉式标题、增粉式开头、增粉式主体。
- **后 30% 走 conv**：在结尾前用 1 个过渡段（"如果你正好需要 / 不少同学私信问"），然后接一个**轻量硬 CTA**：小尺寸二维码 + 1 句话课程钩子。
- 二维码 **必须有**，但比 conv 小，置于尾图前。
- 必带块：fan 的全要 + ⑦ CTA（轻量版） + 按画像决定是否带 ⑧。

## 目的 × 客户画像 二维交叉要点

| Q0 \ Q1 | B 端 | C 端 |
|---|---|---|
| **fan** | 行业洞察口吻；结尾"转发给同业"；CTA 不带销售话 | 个人收益口吻；结尾"转发给你身边考证朋友"；CTA 不带销售话 |
| **conv** | 沉稳商务，合规风险 + 批量培训 + "商务专线"；CTA tone = `audience_design.b_end` | 醒目直白，窗口期 + 个人收益 + "立即咨询"（合规前提下）；CTA tone = `audience_design.c_end` |
| **hybrid** | 前段行业洞察 → 后段商务对接小尾巴 | 前段个人故事 → 后段课程钩子小尾巴 |

## news 的 3 种目的对应文体

| Q0 | 文体 |
|---|---|
| **external_pr**（对外宣传） | 强调"我们办了什么大事/我们和谁合作"，正式但有传播性；结尾鼓励转发 |
| **industry_rel**（行业关系） | 强调"主办/承办/协办单位"全称、人员职务，正式克制，**不带营销** |
| **internal_celebrate**（内部喜讯） | 强调"我们的学员/教师拿了什么奖"，亲切，可适度轻松 |

→ 三种都不强加 CTA / 不放二维码。news 类不是带货场景。

---

## holiday 的 3 种目的对应文体

| Q0 | 文体 |
|---|---|
| **pure_notice**（纯通知） | 最干净版本，贺词 + 放假表 + 值班联系 + 落款。不带营销小尾巴 |
| **fan_flavored**（节日借势增粉） | 贺词更有故事感（具体到岗位、具体到当年形势），结尾鼓励"转发给一线建设者" |
| **conv_flavored**（含营销小尾巴） | 在落款后**独立成段**加 ⑦ 轻量 CTA，按画像走 `audience_design.{b_end\|c_end}.cta_tone`；节日不是带货场景，CTA 必须克制 |

→ holiday 的 designer_mode 永远是 b_end（节日不喊口号），即使 Q0 选 conv_flavored 也按 b_end 视觉规范渲染 CTA。

## 审核钩子（供 audit-checklist 引用）

每篇推文输出时，审核报告必须额外检查：

- Q0 是否被显式记录在 `audit-report.md` 头部
- 当前推文的 **CTA tone、必带块、二维码处理** 是否与 Q0 的对应规范一致
- 如 Q0 = fan，文中**不应**出现"立即报名 / 扫码咨询 / 限时"等转化话术
- 如 Q0 = conv，**必须**出现二维码 + 联系电话 + 报名/咨询入口三件之一
