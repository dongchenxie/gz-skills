# gzcots-holiday

**类型**：节日放假通知
**触发感**：维系关系存在感
**自动化程度**：**高**（版式固定、字段少）

## 启动前置检查

同 `gzcots-publish/SKILL.md`。

## 输入：4 道必问

**Q1** 节日名称（春节 / 元旦 / 清明 / 劳动节 / 端午 / 中秋 / 国庆 / 教师节 / 双节 / 其他）。

**Q2** 放假起止日期（如 `2026-10-01` 至 `2026-10-07`）。

**Q3** 上班 / 复课日期。

**Q4** 是否加营销小尾巴？
- A. 否（纯通知，最干净）
- B. 是 —— **B 端版**（"祝合作企业事业兴旺，节后有培训需求随时联系"）
- C. 是 —— **C 端版**（"节后报名季即将开启，关注我们获取课程信息"）

值班联系方式默认使用 `_shared/brand.yaml` 的 `school.hotline`。

## 抓取

无。本类推文不抓取任何外部内容。

## 撰稿规则

- 标题格式："关于 XXX 放假安排的通知" 或 "XXXX 放假通知"（参考用户历史 3 篇推文的实际标题习惯，**首次运行 skill 时把它记录到 brand.yaml 的 `holiday.title_template`**）。
- 正文不超过 200 字。
- 节日相关祝福语 1 句即可，避免过度煽情。
- 如 Q4 选 B/C，营销小尾巴必须**独立成段且在落款后**，不能混在通知正文里。

## 渲染

按 `_shared/135-editor.md` 骨架渲染。必带块：①②④⑨；Q4 选 B/C 时增加 ⑦ CTA。

## 审核 / 输出

只跑维度 1（错字）+ 维度 2（排版）。日期格式必须统一（用户偏好：`X月X日` 或 `XX/XX`，首次确认后记到 brand.yaml）。

输出双产物（与其他 sub-skill 一致）。
