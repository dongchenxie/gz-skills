# gzcots-tips

**类型**：温馨提示 + 营销
**触发感**：制造避险感（"别忘了"、"再不办就晚了"、"政策变了你知道吗"）
**和 gzcots-policy 的区别**：政策解读偏"解释新规"，温馨提示偏"提醒老规矩到期"。前者是新闻向，后者是日历向。

## 启动前置检查

同 `gzcots-publish/SKILL.md`。

## 输入：4 道必问

**Q1（必须先问）** 客户画像（同 gzcots-policy 的 5 选）。

**Q2** 提示主题（开放问答），常见：
- 某证书 / 学时即将到期
- 某项资质改革窗口期
- 培训政策更新
- 申报系统开放 / 关闭

**Q3** 政策依据 URL（可选 —— 没有就跳过抓取，但推文里**不得**编造具体条款）。

**Q4** 关联课程（多选）。

## 抓取（如 Q3 有 URL，按 gzcots-policy 的子 agent 流程进行，否则跳过）

## 撰稿规则

- **语气："科普 + 实际为学员考虑"**。不要紧迫感拉满，反而要稳。
- 开头用"温馨提示"或"近期收到不少咨询"作锚。
- 中段拆解"为什么要重视"→ "通常怎么做"→ "我们能帮什么"。
- **B 端版本**：强调"合规风险"+"统一管理省心"。
- **C 端版本**：强调"过期了真的没办法补"+"我们有合规通道"。
- 不出现"包过 / 保过"等承诺式表述。

## 渲染

按 `_shared/135-editor.md` 骨架，必带块：①②④⑤⑦⑨；C 端必带 ⑧。

## 审核 / 输出

同 `gzcots-policy` 的审核 + 双产物输出。
