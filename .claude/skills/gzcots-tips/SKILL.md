# gzcots-tips

**类型**：温馨提示 + 营销
**触发感**：制造避险感（"别忘了"、"再不办就晚了"、"政策变了你知道吗"）
**和 gzcots-policy 的区别**：政策解读偏"解释新规"，温馨提示偏"提醒老规矩到期"。前者是新闻向，后者是日历向。

## ⚠️ 必须项（违反任意一条即审核红线）

- **信源白名单**：所有引用条款、数字、日期必须来自 `_shared/sources.yaml`，**没有 URL 就不引用具体数字**。
- **抓取在 sub-agent 内**：如 Q3 有 URL，按 `_shared/research-strategy.md` 派 sub-agent 抓取。
- **三层并发**：若用户给的是市级通知，sub-agent 仍需并发查省厅+部委是否有上位法（避免漏掉更权威条款）。
- **先问 Q0**：按 `_shared/article-goals.md` 落地文体；本类默认推 hybrid（提示类天然偏共鸣）。
- **配图（inline）必须自动生成**：Research 后、渲染前派 sub-agent 调 `scripts/gen-image.mjs --role inline`，产出 1 张装饰图。头图 ①、尾图 ⑨ **不替换**。详见 `_shared/image-generation.md`。

## 启动前置检查

同 `gzcots-publish/SKILL.md`。

## 输入：先 Q0，再 Q1–Q4

**Q0（必须最先问）** 本篇核心目的：
- A. **fan**（增粉，借提示话题做行业共鸣）
- B. **conv**（转化，证书到期前推合规通道）
- C. **hybrid**（混合，**默认推荐**）

**Q1** 客户画像（同 gzcots-policy 的 5 选）。

**Q2** 提示主题（开放问答），常见：
- 某证书 / 学时即将到期
- 某项资质改革窗口期
- 培训政策更新
- 申报系统开放 / 关闭

**Q3** 政策依据 URL（可选 —— 没有就跳过抓取，但推文里**不得**编造具体条款）。

**Q4** 关联课程（多选）。

## Research（如 Q3 有 URL）

派 sub-agent 执行 `_shared/research-strategy.md` 的三层并发：

- 输入 `primary_url = Q3`，先抓主 URL。
- 并发在国家部 + 省厅 + 受众市局检索同主题更新文（避免引用了一份已被新文废止的旧规）。
- 输出结构化 JSON 回主上下文，**不回 HTML**。

如 Q3 为空：跳过 Research，文中不出现任何具体数字 / 期限 / 文号。**含糊表述（"近期""有规定要求"）允许，编造数字 = 红线**。

## 配图生成（Research 后、渲染前 · 必须 sub-agent · 仅 inline）

按 `_shared/image-generation.md` 契约派 `Agent`（`subagent_type: general-purpose`）调 `scripts/gen-image.mjs --role inline`：

- **inline × 1**：`--article-type tips --audience {Q1} --goal {Q0} --theme "{Q2 主题}"`
- `--style-extra` 倾向"平静提醒感"，例如"持证人在桌前对照学时台账" / "施工员翻看证书有效期"。**避免吓唬感**（暴雷、闪电、警报等不要用）。

头图 ①、尾图 ⑨ **不替换**。sub-agent 仅返回 1 个 `inline_urls[0]`，按 ⑩ 块样式插在 ④/⑤ 块之间（推荐放第一个 ⑤ 重点卡片之前作"提示场景"破题）。

## 撰稿规则（Q0 × Q1 分流）

按 `_shared/article-goals.md` 二维交叉表，**叠加本类的语气基调**：

- **基调**："科普 + 实际为学员考虑"。不要紧迫感拉满，反而要稳。
- 开头用"温馨提示"或"近期收到不少咨询"作锚。
- 中段拆解："为什么要重视"→"通常怎么做"→"我们能帮什么"。

按 Q0 切换：

- **fan**：用"我们最近发现 X" / "你身边有没有这种情况"开场，结尾鼓励转发；不放二维码。
- **conv**：用"再不办 → 后果"+"我们的合规通道"为主线；结尾必带 ⑦ CTA（二维码+电话）。
- **hybrid**：前段共鸣 + 后段轻量 CTA。

按 Q1 切换：

- **B 端**：强调"合规风险"+"统一管理省心"。
- **C 端**：强调"过期了真的没办法补"+"我们有合规通道"。
- 不出现"包过 / 保过"等承诺式表述。

## 渲染

按 `_shared/135-editor.md` 骨架，**必带块按 Q0 切换**：

| Q0 | 必带块 |
|---|---|
| fan | ①②④⑤⑦（软 CTA）⑨ |
| conv | ①②④⑤⑥⑦⑨；C 端必带 ⑧ |
| hybrid | ①②④⑤⑦（轻量）⑨；C 端必带 ⑧ |

## 审核 / 输出

同 `gzcots-policy` 的审核 + 双产物输出。额外检查：

- Q0 一致性（见 `article-goals.md` 审核钩子）。
- 若 Q3 为空，文中是否出现具体数字 / 期限 / 文号 → 任意出现 = 红线。
- 配图（inline）张数是否 = 1；① 头图、⑨ 尾图未被替换；图风格未"暴雷化吓唬人"（详见 audit-checklist 第 6 维）。
